# Pizza

## О проекте

Пример приложения на SwiftUI и Firebase, 2022 год: каталог, корзина, профиль и административные экраны.

Код: `Pizza/Screen/`, `Pizza/ViewModel/`, `Pizza/Service/`. Для запуска требуется собственная конфигурация Firebase. В сетевом слое сохранена ранняя реализация с callback API; обработка ошибок и завершение операций требуют доработки перед production-использованием.

Это исторический пример iOS/Android-кода. Основное текущее направление — Flutter / Dart; актуальный открытый Flutter-проект — [Objectno](https://github.com/nskomega/Objectno).
